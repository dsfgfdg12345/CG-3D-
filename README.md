CG 原画就业前景：游戏行业对原画师的需求与薪资真相
CG 原画是游戏美术的源头岗位，负责把文字需求变成可视化的角色、场景和道具设定。很多人被“原画师”三个字吸引入行，却发现市场分化严重：有人月薪两三万，有人接不到单。真相是，游戏行业对原画的需求一直在，但需求结构变了——不缺会画图的人，缺能设计、能落地、能配合项目的人。

一、需求：游戏是主战场，但岗位在细分。 角色原画、场景原画、概念设计、美宣插画、UI 图标和道具设计是常见方向。手游、端游、主机游戏、独立游戏都需要原画，但要求不同：大厂分工细，角色和场景分开，概念设计偏前期探索；中小团队往往一人多能，角色场景都要会，还要能对接建模和特效。外包需求量大，但单价和周期波动明显。近年风格化项目、二次元、国风和潮玩类需求增长，写实硬核项目更看功底和项目经验。影视、动画和广告也招原画，但游戏仍是最大需求方。AI 提高了出图效率，但短期替代不了设计判断、风格统一和项目落地能力。

二、技能要求：设计能力是分水岭。 新手常以为原画就是画得好看，实际岗位要解决设计问题：角色剪影是否清楚、服装结构是否合理、场景是否有空间和功能逻辑、道具是否可建模。软件上 Photoshop 是基础，会 Blender 或 3D 辅助定透视和光影是加分项。风格上要能适应项目，二次元、国风、写实、欧美卡通各有语言。更重要的是落地意识：设计要考虑建模面数、材质实现、动画活动和引擎性能，不能画完不管。沟通和规范也不能少：命名清楚、分层交付、能按策划和主美需求改稿。只会临摹和堆细节，不会原创设计，很难进商业项目。

三、薪资真相：跨度大，作品集决定起点。 一线城市初级原画师月薪大致 6K 到 10K，能完成基础角色或场景设定；中级 10K 到 18K，能独立负责项目模块、风格统一、对接上下游；高级或主美级 18K 到 30K 以上，能定风格、带团队、控质量。大厂有项目奖金，外包和中小团队底薪偏低但项目多。二次元和风格化项目需求大，竞争也激烈；写实硬核项目门槛高，但资深人才稀缺。月入过万在中级岗位不罕见，但刚入行就过万很少。城市、公司类型、项目体量和是否懂 3D 辅助，都会明显影响薪资。

四、入行真相：作品集比学历和证书重要。 招聘方看作品集，先看前三张主图，再看设计逻辑和过程。作品集要有完整项目：角色三视图、表情和动作示意、场景氛围图、道具分解和风格测试。只放临摹或零散插图，很难证明能进项目。培训班输出大量相似风格作品，反而降低辨识度。真实项目、外包、Game Jam 或独立游戏合作，都比空泛的“精通”有说服力。常见误区是只追求画面精细，忽略剪影和设计；只画角色不画场景，就业面窄；不会 3D 辅助，透视和光影容易散；忽视落地，设计无法建模。

五、现实路径。 先选一个方向深挖：二次元角色、国风场景或风格化概念。用三到五个完整项目建立统一风格的作品集，补齐 3D 辅助和落地意识，再通过外包、独立游戏或实习积累经验。不要一开始盯着月薪过万，先看能否稳定交付一个可进项目的设计包。CG 原画的就业前景取决于“能不能设计并落地”，不是“会不会画图”。设计能力、风格适应、落地意识和项目经验，才是这一行最硬的通行证。
